decrypt - decrypt a ciphertext (shows the plaintext, interactive terminal only)

Usage
  java [-D...] -jar {jar} dec
       [--config <file>] [--admin-pass-file <file>] [--lang en|ko]

Options
  --config <file>   External Properties file (optional, same rules as encrypt)
  --admin-pass-file <file>
                    Admin password file (non-interactive, mode 600)
                    Without it the admin password is asked (hidden)
  --lang en|ko      Message language for this run (optional)
  The ciphertext is not an argument; it is typed as hidden input.
  The key is found by the key ID in the ciphertext (pass or key, no type).

Result
  Admin password (hidden):   (admin check first, then the ciphertext)
  Ciphertext (hidden):
  Decrypted: <plaintext>
  If the key ID or authentication tag check fails, it ends with an error
  and no plaintext (KEY_ID_MISMATCH: key ID not registered, INTEGRITY, ...).

Examples
  java -jar {jar} dec
  java -jar {jar} dec --config app.properties
