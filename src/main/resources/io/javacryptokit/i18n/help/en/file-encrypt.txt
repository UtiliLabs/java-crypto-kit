file encrypt - encrypt a file (any content, JCKF v2, streaming for large files)

Usage
  java [-D...] -jar {jar} file encrypt --in <file>
       --out <file> [--type pass|key] [--key-id <ID>]
       [--config <file>] [--lang en|ko]

Options
  --in <file>       File to encrypt (required)
  --out <file>      Result file (required).
                    An existing file is never overwritten.
  --type pass|key   Key type (optional, same rules as encrypt)
  --key-id <ID>     A registered key ID (optional, type found from the key)
  --config <file>   External Properties file (optional, same rules as encrypt)
  --lang en|ko      Message language for this run (optional)
  The original is not changed. Each run gives a different result.

Result
  Encrypted: data.csv -> data.jck (key ID key01, 1049071 bytes)

Examples
  java -jar {jar} file enc --in a.pdf --out a.jck
  java -jar {jar} file enc --in a --out b --type key
