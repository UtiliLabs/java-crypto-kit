help vault - read the key from HashiCorp Vault KV v2 (crypto.key.source=vault)

Prepare
  java -jar {jar} keygen --out prod02.key
  vault kv put secret/java-crypto-kit/prod key=@prod02.key
  (note the printed version, e.g. 1)
  Policy: path "secret/data/java-crypto-kit/prod"
          { capabilities = ["read"] }

Settings (config set or external Properties)
  crypto.key.source=vault          crypto.key.id=prod02
  crypto.key.type=key              (to use this key when no type is given)
  crypto.vault.url=https://vault.example.internal:8200
  crypto.vault.mount=secret        crypto.vault.path=java-crypto-kit/prod
  crypto.vault.field=key           crypto.vault.ver=1
  crypto.vault.token.file=/run/secrets/vault-token
  (or crypto.vault.token.env=VAULT_TOKEN; no token in settings or -D)
  crypto.vault.ca.file=/etc/java-crypto-kit/vault-ca.pem   (for a private CA)
  If crypto.key.active.key names another key ID, set it to prod02 or add
  --key-id prod02 to the command.

Check (--offline: settings, token and CA file only, no connection)
  java -jar {jar} doctor --offline
  java -jar {jar} doctor

Pass keys and further keys: config key add --source vault --location
<path>#<field> (read once when registering, fingerprint pinned).
HTTPS only (certificate and host name always verified, no redirects).
On failure it stops with [reason: KEY_SOURCE] and never uses another key.
Details (retries, errors, key rotation): docs/user-guide.md 8.1
