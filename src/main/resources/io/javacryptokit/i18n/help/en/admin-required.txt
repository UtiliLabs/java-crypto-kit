java-crypto-kit CLI {version} - the admin password must be set first

Set a CLI admin password before running operational commands.
Setup updates this JAR with the verifier and random PASS (Passphrase)
and KEY (AES Key) keys.

  {update} admin setup

Input        new password -> confirmation (hidden)
Unattended   admin setup --admin-pass-file <file>
Rules        10-128 characters with a letter, a digit and a special character
             (ASCII only, no spaces)
Then         run commands with the same JAR.
Scope        CLI only. The Java API and Tomcat decrypt without the password.
Details: admin setup --help, docs/user-guide.md 1.4

Help and version: java -jar {jar} --help
Command help:     java -jar {jar} api --help
Examples:         java -jar {jar} api jwt --examples
