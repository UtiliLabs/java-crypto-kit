config help - manage the JAR built-in settings; list of all settings

Commands (work on the JAR file only, no rebuild)
  config show                         JAR built-in settings and key list
  config history                      Settings change history
  config set <setting>=<value> ...    Create a new JAR with changed settings
  config embed-key --from-file <key>  Create a new JAR with an AES key built in
  config key add|use|remove           Add, use (as default) or remove a key
  Options of each command: add --help, e.g. config set --help
  A change of keys needs CHANGE or --yes, also when creating a new JAR.

Setting priority: JVM -D > external Properties > JAR built-in value
  External Properties: --config <file>, -Dcrypto.config.file=<file>,
                       or the environment variable CRYPTO_CONFIG_FILE
  -D goes between java and -jar (rejected for crypto.key.embedded, ignored for
  crypto.jvm.override.enabled). Settings are read at startup.

Examples
  java -jar {jar} config set crypto.lang=en --operator ops
  java -Dcrypto.config.file=app.properties -jar {jar} info

{settings}
Key list items crypto.keys.<key ID>.<item> (type, source, embedded, file, env,
  vault.path, vault.field, vault.ver, aws.kms.data-key.file, kdf,
  kdf.iterations, salt, fingerprint) are created by config key add.
