kms datakey - create a data key file for aws-kms (needs the AWS SDK bundle)

Usage (use -cp with the SDK bundle instead of java -jar)
  java -cp <classpath> io.javacryptokit.cli.CryptoCli kms datakey
       --out <file> [--from-file <key file>] [--config <file>]
       [--reason <text>] [--operator <ID>]
       [--admin-pass-file <file>] [--lang en|ko]

Classpath CP (the JAR and the aws-kms-lib folder in the current folder)
  PowerShell: $CP = "{jar};aws-kms-lib/*"
  Linux     : CP="{jar}:aws-kms-lib/*"
  How to set it, --from-file example: docs/user-guide.md 2.17

Options
  --out <file>             Data key file to create (required, not overwritten,
                           POSIX 600)
  --from-file <key file>   Wrap an existing key (keygen format) with KMS; the
                           key and key ID stay, so existing ciphertext keeps
                           working. Without it: new key by GenerateDataKey.
  --config <file>          External Properties with these settings (optional if
                           set in the JAR or by -D): crypto.key.source=aws-kms,
                           crypto.aws.kms.key.id, crypto.aws.region,
                           crypto.key.id
  --reason <text>          Reason (required). Asked in an interactive terminal;
                           otherwise an error before KMS is called.
  --operator <ID>          Operator ID (optional, shown in the result only)
  --admin-pass-file <file> Admin password file (non-interactive, mode 600)
                           Without it the admin password is asked (hidden)
  --lang en|ko             Message language for this run (optional)
  For the crypto.key.* AES key. Pass keys and further keys: config key add
  --source aws-kms (help config key add). The data key itself is never shown
  (only the KMS-protected file remains). No JAR is changed, so the reason and
  operator are not stored anywhere.

Result
  File       : /etc/java-crypto-kit/prod.datakey
  Mode       : new data key (KMS GenerateDataKey)
  Key ID     : key01
  Fingerprint: 9d2e... (64 characters)
  Reason     : prepare the production data key
  History    : not stored (no JAR is changed, so config history has none)
  Set this path as crypto.aws.kms.data-key.file (help aws-kms).

Examples
  java -cp "$CP" io.javacryptokit.cli.CryptoCli kms datakey --out prod.datakey
