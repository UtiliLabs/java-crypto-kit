config key remove - remove a key from the key list (updates the current JAR)

Usage
  {update} config key remove --key-id <ID>
       --operator <ID> [--reason <text>] [--jar <jar>]
       [--replace] [--yes]
       [--admin-pass-file <file>] [--lang en|ko]

Options
  --key-id <ID>     Key ID to remove (required)
  --operator <ID>   Operator ID for the history (required)
  --reason <text>   Reason for the history (required, asked interactively)
  --jar <jar>       JAR to change (optional, default: the running JAR)
  --replace           Compatibility flag. Updates the same path.
  --yes             Skip the CHANGE confirmation (not the reason)
  --admin-pass-file <file>
                    Admin password file (non-interactive, mode 600)
                    Without it the admin password is asked (hidden)
  --lang en|ko      Message language for this run (optional)
  A default key and the crypto.key.* AES key cannot be removed. The JAR is
  updated in place and can no longer decrypt ciphertext of the removed key,
  so rekey that ciphertext first.
  A removed key ID can be used again only to restore the same key.

Result
  Updated JAR : /opt/app/java-crypto-kit-{version}.jar
  Changes     : crypto.keys.p1.type (pass -> (none))
                ...
  Removed key : p1

Examples
  {update} config key remove --key-id p1 --operator ops
