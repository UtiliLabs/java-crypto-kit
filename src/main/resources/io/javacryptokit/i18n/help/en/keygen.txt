keygen - create a new AES-256 key file (only when you need a key-type key)

Usage
  java -jar {jar} keygen --out <key file>
       [--reason <text>] [--operator <ID>]
       [--admin-pass-file <file>] [--lang en|ko]

Options
  --out <key file>   Key file to create (required). The parent folder must
                     exist; an existing file is never overwritten.
  --reason <text>    Reason (required). Asked in an interactive terminal;
                     otherwise an error before any key is made.
  --operator <ID>    Operator ID (optional, shown in the result only)
  --admin-pass-file <file>
                     Admin password file (non-interactive, mode 600)
                     Without it the admin password is asked (hidden)
  --lang en|ko       Message language for this run (optional)
  Writes 32 secure random bytes as one standard Base64 line (mode 600 on
  Linux/macOS). An interactive terminal shows that same line (the generated
  value) once; a non-interactive run does not (the key file is the original).
  keygen changes no JAR, so the reason and operator are not stored anywhere.
  It does not create passphrases (pass keys: config key add --generate).

Result
  Key file    : C:\Users\me\jck-secure\example.key
  Fingerprint : 3f9a... (64 characters)
  Reason      : prepare the production key
  History     : not stored (no JAR is changed, so config history has none)
  Interactive: then type, key ID (not registered), format, value line, note.

Examples (Windows PowerShell)
  mkdir $HOME\jck-secure
  java -jar {jar} keygen --out $HOME\jck-secure\example.key
Examples (Linux)
  mkdir -m 700 ~/jck-secure
  java -jar {jar} keygen --out ~/jck-secure/example.key
