fingerprint - compare keys exactly by fingerprint (SHA-256, 64 characters)

Usage
  java [-D...] -jar {jar} fingerprint
       [--type pass|key] [--key-id <ID>] [--config <file>] [--lang en|ko]
  java -jar {jar} fingerprint --key-file <key file>
       [--lang en|ko]

Options
  --type pass|key     The default key of the type (optional). Without it: the
                      default key for new encryption
  --key-id <ID>       A registered key ID (optional, type found from the key)
  --config <file>     External Properties file (optional). Otherwise the key of
                      the current settings (remote key sources are contacted)
  --key-file <file>   Show the fingerprint of a key file (keygen format)
                      instead. Not with --config, --type or --key-id.
  --lang en|ko        Message language for this run (optional)

Result
  Key source : embedded
  Location   : JAR built-in (crypto.key.embedded)
  Key ID     : key01
  Key type   : key
  Key status : custom key
  Fingerprint: 5b1c... (64 characters, not the key itself)
  The same fingerprint means the same key (pass: of the derived AES key).
  info and config show display only the first 12 and last 8 characters.

Examples
  java -jar {jar} fingerprint
  java -jar {jar} fingerprint --type key
  java -jar {jar} fingerprint --key-file example.key
