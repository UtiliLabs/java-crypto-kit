admin setup - set the CLI admin password for the first time (in place)

Usage
  {update} admin setup [--operator <ID>]
       [--pass-export <file>]
       [--admin-pass-file <file>] [--replace] [--lang en|ko]

Options
  --replace         Compatibility flag for the same JAR path.
  --operator <ID>   Operator ID for the history. Defaults to SYSTEM.
  --admin-pass-file <file>
                    Non-interactive (CI): a file with the new password on one
                    line (a temporary file with mode 600, delete it)
  --lang en|ko      Message language for this run (optional)
  Runs only on a JAR without an admin password (a set one is never replaced).
  Interactive: new password -> confirmation (hidden, twice).
  Interactive use can enter setup from another command on either OS.
  Rerun that command with the same JAR after setup.

Rules
  10-128 characters with at least one letter (A-Z, a-z), one digit (0-9) and
  one special character (ASCII symbol such as !@#$%). Spaces and non-ASCII
  characters are not allowed. Upper and lower case are not required
  separately. 12-16 characters or more are recommended for production.

Result
  Setup creates random PASS (Passphrase) and KEY (AES Key) in this JAR.
  The configured JAR has a different SHA-256 from the distribution JAR.
  Back up the configured JAR securely for all servers using its keys.
  Use --pass-export <file> at setup to save a protected pass recovery file.
  The original embedded passphrase cannot be retrieved later.

Examples
  {update} admin setup
  {update} admin setup --admin-pass-file admin.pw
