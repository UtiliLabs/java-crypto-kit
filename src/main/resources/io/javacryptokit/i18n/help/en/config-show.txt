config show - settings stored in the JAR and its key list (admin, no -D)

Usage
  java -jar {jar} config show [--jar <jar>]
       [--admin-pass-file <file>] [--lang en|ko]

Options
  --jar <jar>    JAR to read (optional, default: the running JAR)
  --admin-pass-file <file>
                 Admin password file (non-interactive, mode 600)
                 Without it the admin password is asked (hidden)
  --lang en|ko   Message language for this run (optional)
  For another JAR (--jar) that JAR's admin password is checked as well.

Result (part)
  JAR file     : java-crypto-kit-{version}-cfg.jar (version {version})
  State        : 2 change(s), last 2026-11-22T05:30:12Z by ops
  Admin        : password set (sensitive commands need it)
  Key type     : pass
  Default keys : pass=pass-default, key=key01
  Keys         :
    key01: key, embedded, custom key, crypto.key.*
      Fingerprint:
        ab12cd34...(all 64)
    pass-default: pass, embedded, public default key
      KDF: pbkdf2-sha256, 600,000 rounds
      Salt: ...(Base64)   Salt SHA-256: ...(64)
  Settings hash: sha256:...      (settings file content, not a key)
  crypto.key.id = key01          (then every built-in value; key: (secret))
  External keys show their pinned fingerprints. To view a key value, run
  config key show --key-id <ID> --show in an interactive terminal.
  Keys used at run time: info, fingerprint. Exit code 1 if history damaged.

Examples
  java -jar {jar} config show
  java -jar {jar} config show --jar new.jar
