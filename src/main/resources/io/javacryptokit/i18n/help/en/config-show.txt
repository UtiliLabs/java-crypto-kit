config show - current settings stored inside a JAR file and the last-change summary

Usage
  java -jar {jar} config show [--jar <jar>] [--lang en|ko]

Options
  --jar <jar>    JAR to read (optional). Default: the running JAR.
  --lang en|ko   Message language for this run only (optional).

What it does
  Reads only the JAR file: every built-in value in file order, the summary (key source, key ID, key status with
  fingerprint, language, warnings, JVM override, algorithm, output, pool), the initial build time, the last modified
  time, operator, total number of changes and the last changed settings. External Properties, JVM -D and environment
  variables are not read, so it works even when they are broken. The built-in key value is never shown.
  For every change from the first one use config history; for runtime values use info.

Examples
  Windows PowerShell
    java -jar .\{jar} config show
    java -jar .\{jar} config show --jar .\java-crypto-kit-{version}-configured.jar
  Linux
    java -jar ./{jar} config show --jar /opt/tomcat/lib/{jar}

Expected result (excerpt)
  Initial build time: 2026-11-21T01:02:03Z (UTC, manifest Build-Time)
  Internal settings state: changed (modified by config set / embed-key)
  Last modified: 2026-11-21T05:30:12Z (UTC)
  Last operator: 123456 (recorded ID, not authentication)
  Total changes: 2
  crypto.key.embedded = <hidden for security> (set - replaced key ..., key fingerprint 5b1c...)

Errors and fixes
  Internal settings state: history check FAILED -> exit code 1; see config history and use a trusted JAR.
  [reason: USAGE] It is not a java-crypto-kit JAR -> check --jar.

Related: config history, config set, config embed-key, info
