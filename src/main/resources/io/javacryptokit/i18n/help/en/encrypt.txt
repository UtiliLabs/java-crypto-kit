encrypt - encrypt a value (DB password, user name, ...)

Usage
  java [-D...] -jar {jar} enc
       [--type pass|key] [--key-id <ID>] [--config <file>] [--lang en|ko]

Options
  --type pass|key   Key type (optional). Default: crypto.key.type (pass)
  --key-id <ID>     A registered key ID (optional, type found from the key).
                    With --type, the type is checked. Without either: the
                    default key of the type (see config show)
  --config <file>   External Properties file (optional). Without it:
                    -Dcrypto.config.file, then the environment variable
                    CRYPTO_CONFIG_FILE, then the JAR settings (as in Tomcat).
  --lang en|ko      Message language for this run (optional)

Result
  Value to encrypt (hidden):
  ENC[v1:app-pass:...]
  The whole line is the ciphertext (different every time). It holds the key
  ID, so decryption needs no type. With the base64 setting it is B64[...].
  Put it as is into password="..." of the Tomcat Resource (help tomcat).

Examples
  java -jar {jar} enc
  java -jar {jar} enc --type key
  java -jar {jar} enc --key-id app-pass
