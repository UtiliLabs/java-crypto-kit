java-crypto-kit CLI {version} - Java security toolkit

Usage: java [-D...] -jar {jar} <command> [options]

Admin (set once before using the CLI)
  admin setup              Set the admin password (new JAR)
  admin password change    Change the admin password (new JAR)
Values
  encrypt                  Encrypt a value
  decrypt *                Decrypt a value
  verify                   Check a ciphertext (no plaintext output)
Files
  file encrypt             Encrypt a file
  file decrypt *           Decrypt a file
Keys
  keygen *                 Create an AES key file
  fingerprint              Show the key fingerprint
  rekey *                  Re-encrypt with another key
  kms datakey *            Create an AWS KMS data key file
Settings and checks
  config show *            JAR built-in settings and key list
  config history *         Settings change history
  config set *             Change JAR settings (new JAR)
  config embed-key *       Embed an AES key in the JAR (new JAR)
  config key add *         Add a key (new JAR)
  config key use *         Change the default key (new JAR)
  config key remove *      Remove a key (new JAR)
  config key show *        Key management info and value (--show, --export)
  info                     Settings in effect
  doctor                   Check settings and functions

Independent API
  api --help               Independent Java security API commands

* Asks the admin password on every run (unattended: --admin-pass-file <file>).
  The Java API and Tomcat decrypt without the admin password.
Key types: pass (passphrase, default), key (AES key). Encryption picks a key
with --type or --key-id; decryption finds it by the key ID in the ciphertext.
Details: help <command>   (e.g. help config set, decrypt --help)
Examples: <command> --examples (e.g. file --examples)
Settings: help config    Key list: help config key
Integration: help tomcat / help vault / help aws-kms
Every command: --lang en|ko (language of this run), --help (command help)
External config file: --config <file>, -Dcrypto.config.file, CRYPTO_CONFIG_FILE
Put -D<setting>=<value> between java and -jar, e.g.:
  java -Dcrypto.lang=en -jar {jar} info
Exit code 0 = success, 1 = failure. Errors are one line on standard error:
  [java-crypto-kit] [reason: CODE] cause Action: ...
Guide: docs/user-guide.md (GitHub repository; command cookbook: appendix A)
