doctor - check that settings apply and the keys and encryption work

Usage
  java [-D...] -jar {jar} doctor
       [--config <file>] [--offline] [--lang en|ko]

Options
  --config <file>   External Properties file (optional, same rules as Tomcat)
  --offline         Do not contact Vault or AWS KMS; check settings, token,
                    SDK and files only (SKIP)
  --lang en|ko      Message language for this run (optional)

Result
  [PASS] Settings loaded
  [INFO] Key type pass, active pass pass-default, active key key01
  [INFO] Key key01 (key, default, crypto.key.*):
         embedded, JAR built-in (crypto.key.embedded)
  [PASS] Key loaded: key01, custom key, fingerprint ab12cd34ef56...7890abcd
  [PASS] Encrypt, decrypt and tamper rejection check OK
  Result: PASS
  Each registered key is checked. A failed item shows [FAIL] and one action
  line below it. Exit code 1 on FAIL. Tomcat startup and DB are not checked.

Examples
  java -jar {jar} doctor
  java -jar {jar} doctor --config app.properties --offline
