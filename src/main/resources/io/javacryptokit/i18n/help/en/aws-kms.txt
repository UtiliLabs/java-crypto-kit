help aws-kms - use a data key protected by AWS KMS (crypto.key.source=aws-kms)

1) Install the optional AWS SDK bundle (needed only for aws-kms)
   Put aws-kms-lib/*.jar from java-crypto-kit-aws-kms-lib-{version}.zip
   into CATALINA_BASE/lib for Tomcat; for the CLI add it with -cp
   (java -jar ignores -cp). Classpath CP (current folder):
   PowerShell: $CP = "{jar};aws-kms-lib/*"
   Linux     : CP="{jar}:aws-kms-lib/*"
2) Create the data key file (once): kms datakey --help
3) Settings
   crypto.key.source=aws-kms          crypto.key.id=prod01
   crypto.aws.kms.key.id=alias/java-crypto-kit-prod
   crypto.aws.kms.data-key.file=/etc/java-crypto-kit/prod.datakey
   crypto.aws.region=ap-northeast-2   (empty = the SDK default region chain)
4) Check
   java -cp "$CP" io.javacryptokit.cli.CryptoCli doctor --offline
   java -cp "$CP" io.javacryptokit.cli.CryptoCli doctor

Pass keys and further keys: config key add --source aws-kms --location
<file> (for pass, KMS wraps the derived AES key in the same format).
Permissions: kms:Decrypt for the WAS; kms:GenerateDataKey or kms:Encrypt to
create the data key. Credentials come only from the AWS SDK standard chain
(IAM role, profile, environment variables).
Details (CP, errors and recovery): docs/user-guide.md 8.2
