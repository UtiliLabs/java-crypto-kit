file decrypt - decrypt a file made by file encrypt (JCKF v1)

Usage
  java [-D...] -jar {jar} file decrypt --in <file>
       --out <file> [--config <file>]
       [--admin-pass-file <file>] [--lang en|ko]

Options
  --in <file>       Encrypted file (required)
  --out <file>      Result file (required).
                    An existing file is never overwritten.
  --config <file>   External Properties file (optional, same rules as encrypt)
  --admin-pass-file <file>
                    Admin password file (non-interactive, mode 600)
                    Without it the admin password is asked (hidden)
  --lang en|ko      Message language for this run (optional)
  The key is found by the key ID in the file header. The result appears only
  after every chunk is authenticated (none on failure).

Result
  Decrypted: data.jck -> data.csv (1048576 bytes)

Examples
  java -jar {jar} file decrypt --in a.jck --out a.pdf
  java -jar {jar} file decrypt --in data.jck --out data.csv
