verify - check that a ciphertext decrypts with a registered key (no plaintext)

Usage
  java [-D...] -jar {jar} verify
       [--config <file>] [--value <ciphertext>] [--lang en|ko]

Options
  --config <file>        External Properties file (optional, same as encrypt)
  --value <ciphertext>   Ciphertext to check (optional, else hidden input).
                         For automation; it stays in the shell history.
  --lang en|ko           Message language for this run (optional)
  The key is found by the key ID in the ciphertext.

Result
  OK
  On failure: exit code 1 with a reason
  (KEY_ID_MISMATCH: key ID not registered, INTEGRITY: other key or damaged).

Examples
  java -jar {jar} verify
  java -jar {jar} verify --value 'ENC[v1:key01:...]'
