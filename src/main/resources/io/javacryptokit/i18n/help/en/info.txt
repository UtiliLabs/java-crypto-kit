info - settings in effect with their origin, and the registered keys

Usage
  java [-D...] -jar {jar} info
       [--config <file>] [--lang en|ko]

Options
  --config <file>   External Properties file (optional, same rules as Tomcat)
  --lang en|ko      Message language for this run (optional)

Result (part)
  Key type   : pass [JAR built-in value]
  Active pass: pass-default [JAR built-in value]
  Active key : key01 [JAR built-in value]

  Key key01 (key, default, crypto.key.*)
    Source     : embedded [JAR built-in value]
    Status     : custom key
    Fingerprint: ab12cd34ef56...7890abcd     (exact comparison: fingerprint)
    Check      : OK
  ...
  JVM -D     : allowed [JAR built-in value]
  Applied -D : crypto.lang
  [ ] is the origin of the value (JAR, external config file, JVM property -D).
  If any key cannot be read: Check FAIL, one error line, exit code 1.

Examples
  java -jar {jar} info
  java -Dcrypto.config.file=app.properties -jar {jar} info
