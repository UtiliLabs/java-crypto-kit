help tomcat - decrypt the DB password of a Tomcat JNDI DataSource

1) Place the JARs: copy the java-crypto-kit JAR (key-embedded in production)
   and the JDBC driver JAR to CATALINA_BASE/lib (only one java-crypto-kit JAR).
2) Encrypt: run encrypt with the same JAR to get ENC[v1:...].
3) Edit the Resource in a Context file Tomcat reads (e.g. META-INF/context.xml
   of the application) with these attributes (username: plain or encrypted):
     factory="io.javacryptokit.jdbc.tomcat.EncryptedDataSourceFactory"
     password="ENC[v1:...]"
   The key is found by the key ID of the ciphertext (pass or key both work).
   Set cryptoPool="dbcp2" or cryptoPool="tomcat-jdbc" on each Resource.
   Omitting cryptoPool uses the valid crypto.pool.factory setting.
4) Only with an external config file add -Dcrypto.config.file=<file>:
   CATALINA_OPTS in bin/setenv.sh (Linux) or bin/setenv.bat (Windows console);
   for a Windows service, the Java Options of the service settings.
5) Restart Tomcat; check in the application: JNDI lookup, getConnection(), SQL

Supported: Tomcat 11.0 (Java 17+), 10.1 (Java 11+), 9.0 (Java 8+), 8.5 (legacy)
Old Oracle JDK 8 (before 8u161) needs the unlimited crypto policy
(crypto.policy=unlimited in java.security).
Errors: the [java-crypto-kit] [reason: CODE] line in the Tomcat log (guide 9.3)
Details (full Resource examples, pool options): docs/user-guide.md chapters 3-4
