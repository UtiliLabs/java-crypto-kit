admin password change - change the CLI admin password (in place, interactive)

Usage
  {update} admin password change [--operator <ID>]
       [--reason <text>] [--replace] [--lang en|ko]

Options
  --operator <ID>   Operator ID for the history. Asked if absent.
  --reason <text>   Reason for the change (required, asked if absent)
  --lang en|ko      Message language for this run (optional)
  Order: current password -> operator ID and reason (when not given) -> new
  password -> confirmation. The new password follows the admin setup rules
  and must differ from the current one. Without the current password it
  cannot be changed (no reset without authentication; if lost, see user
  guide 12.8).

Result
  The same JAR accepts the new password and retains its keys and history.
  Copies made before the change still accept the previous password.

Examples
  {update} admin password change --operator ops
