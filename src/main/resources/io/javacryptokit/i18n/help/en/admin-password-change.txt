admin password change - change the CLI admin password (new JAR, interactive)

Usage
  java -jar {jar} admin password change [--operator <ID>]
       [--reason <text>] [--out <jar>] [--lang en|ko]

Options
  --operator <ID>   Operator ID for the history. Asked if absent.
  --reason <text>   Reason for the change (required, asked if absent)
  --out <jar>       Result JAR (optional, default: next -cfg-N.jar)
  --lang en|ko      Message language for this run (optional)
  Order: current password -> operator ID and reason (when not given) -> new
  password -> confirmation. The new password follows the admin setup rules
  and must differ from the current one. Without the current password it
  cannot be changed (no reset without authentication; if lost, see user
  guide 12.8).

Result
  Admin       : password changed
  Created JAR : C:\work\java-crypto-kit-{version}-cfg-2.jar
  Original JAR: ...-cfg.jar (unchanged, keeps the old password)
  Operator    : ops
  Reason      : scheduled change
  Note        : use the created JAR; discard the original JAR yourself.
  Keys, ciphertext and history stay. The original JAR still opens with the
  old password, so keep or discard it deliberately.

Examples
  java -jar {jar} admin password change --operator ops
