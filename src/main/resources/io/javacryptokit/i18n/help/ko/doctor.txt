doctor - 설정 적용과 키·암복호화 동작 점검(WAS 기동 전)

사용법
  java [-D...] -jar {jar} doctor
       [--config <파일>] [--offline] [--lang en|ko]

옵션
  --config <파일>   외부 Properties 파일(선택, Tomcat과 같은 규칙)
  --offline         Vault·AWS KMS에 연결하지 않고 설정·토큰·SDK·파일만
                    점검합니다(SKIP 표시).
  --lang en|ko      이번 실행의 메시지 언어(선택)

결과
  [PASS] 설정 로딩 정상
  [INFO] 기본 유형 pass, pass 기본 app-pass, key 기본 key01
  [INFO] 키 key01 (key, 기본, crypto.key.*):
         embedded, JAR 내장(crypto.key.embedded)
  [PASS] 키 로딩 정상: key01, 사용자 지정, 지문 ab12cd34ef56...7890abcd
  [PASS] 암호화·복호화·변조 거부 검사 정상
  결과: PASS
  등록된 키마다 따로 점검합니다. 실패 항목은 [FAIL]과 바로 아래 조치 한 줄.
  FAIL이 있으면 종료 코드 1. Tomcat 기동·DB 연결은 점검하지 않습니다.

예제
  java -jar {jar} doctor
  java -jar {jar} doctor --config app.properties --offline
