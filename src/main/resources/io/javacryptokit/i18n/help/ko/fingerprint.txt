fingerprint - 키 지문(SHA-256, 64자)으로 같은 키인지 정확히 비교

사용법
  java [-D...] -jar {jar} fingerprint
       [--type pass|key] [--key-id <ID>] [--config <파일>] [--lang en|ko]
  java -jar {jar} fingerprint --key-file <키 파일>
       [--lang en|ko]

옵션
  --type pass|key     그 유형의 기본 키(선택). 없으면 새 암호화의 기본 키
  --key-id <ID>       등록된 키 ID(선택, 유형 자동)
  --config <파일>     외부 Properties 파일(선택). 없으면 지금 실행 설정의 키
                      (원격 공급원은 실제로 연결)
  --key-file <파일>   대신 키 파일(keygen 형식)의 지문을 보여 줍니다.
                      --config·--type·--key-id와 함께 쓸 수 없습니다.
  --lang en|ko        이번 실행의 메시지 언어(선택)

결과
  키 공급원 : embedded
  키 위치   : JAR 내장(crypto.key.embedded)
  키 ID     : key01
  키 유형   : key
  키 상태   : 사용자 지정
  키 지문   : 5b1c...(64자, 키 원문 아님)
  두 곳의 키 지문이 같으면 같은 키입니다(pass는 파생한 AES 키의 지문).
  info·config show는 지문의 앞 12자와 뒤 8자만 보여 줍니다.

예제
  java -jar {jar} fingerprint
  java -jar {jar} fingerprint --type key
  java -jar {jar} fingerprint --key-file example.key
