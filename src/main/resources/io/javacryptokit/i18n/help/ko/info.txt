info - 실제 적용 설정과 출처, 등록된 키 확인(키 원문 미표시)

사용법
  java [-D...] -jar {jar} info
       [--config <파일>] [--lang en|ko]

옵션
  --config <파일>   외부 Properties 파일(선택, Tomcat과 같은 규칙)
  --lang en|ko      이번 실행의 메시지 언어(선택)

결과(일부)
  기본 유형 : pass [JAR 기본값]
  pass 기본 : app-pass [JAR 기본값]
  key 기본  : key01 [JAR 기본값]

  키 key01 (key, 기본, crypto.key.*)
    공급원 : embedded [JAR 기본값]
    상태   : 사용자 지정
    지문   : ab12cd34ef56...7890abcd     (정확한 비교는 fingerprint)
    조회   : OK
  ...
  JVM -D    : 허용 [JAR 기본값]
  적용 -D   : crypto.lang
  [ ]는 값의 출처(JAR 기본값, 외부 설정 파일, JVM 속성 -D)입니다.
  키를 하나라도 읽지 못하면 조회 FAIL과 오류 한 줄, 종료 코드 1.

예제
  java -jar {jar} info
  java -Dcrypto.config.file=app.properties -jar {jar} info
