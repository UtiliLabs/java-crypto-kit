keygen - 새 AES-256 키 파일 생성(key 유형 키가 필요할 때만)

사용법
  java -jar {jar} keygen --out <키 파일>
       [--reason <사유>] [--operator <ID>]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --out <키 파일>     만들 키 파일(필수). 상위 폴더가 있어야 하며
                      이미 있으면 덮어쓰지 않습니다.
  --reason <사유>     생성 사유(필수). 없으면 대화형 터미널에서 묻고,
                      비대화형이면 키를 만들기 전에 오류로 멈춥니다.
  --operator <ID>     작업자 ID(선택, 결과에만 표시)
  --admin-pass-file <파일>
                      관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                      없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko        이번 실행의 메시지 언어(선택)
  32바이트 보안 난수를 표준 Base64 한 줄로 씁니다(Linux/macOS는 권한 600).
  대화형 터미널이면 같은 한 줄(생성값)을 한 번 보여 줍니다. 비대화형은
  보여 주지 않습니다(키 파일이 원본). keygen은 JAR를 바꾸지 않으므로
  사유·작업자를 어떤 이력에도 저장하지 않습니다.
  Passphrase는 만들지 않습니다(pass 키: config key add --generate).

결과
  키 파일   : C:\Users\me\jck-secure\example.key
  키 지문   : 3f9a...(64자)
  사유      : 운영 키 준비
  이력      : 저장 안 함(JAR를 바꾸지 않는 명령이라 config history에 없음)
  대화형이면 이어서 유형·키 ID(미등록)·형식, 생성값 한 줄, 안내를 보여 줍니다.

예제(Windows PowerShell)
  mkdir $HOME\jck-secure
  java -jar {jar} keygen --out $HOME\jck-secure\example.key
예제(Linux)
  mkdir -m 700 ~/jck-secure
  java -jar {jar} keygen --out ~/jck-secure/example.key
