config key remove - 키 목록에서 키 제거(현재 JAR 갱신)

사용법
  {update} config key remove --key-id <ID>
       --operator <ID> [--reason <사유>] [--jar <jar>]
       [--replace] [--yes]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --key-id <ID>     제거할 키 ID(필수)
  --operator <ID>   이력에 남길 수정자 ID(필수)
  --reason <사유>   이력에 남길 사유(필수, 없으면 대화형 터미널에서 질문)
  --jar <jar>       바꿀 JAR(선택, 기본: 실행 중인 JAR)
  --replace           호환 옵션. 원래 경로에 저장합니다.
  --yes             CHANGE 확인 생략(사유는 생략할 수 없음)
  --admin-pass-file <파일>
                    관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                    없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko      이번 실행의 메시지 언어(선택)
  기본 키와 crypto.key.* AES 키는 제거할 수 없습니다. 같은 JAR를 갱신하며
  제거 뒤에는 그 키로 만든 암호문을 복호화할 수 없으므로 먼저 rekey로
  옮깁니다.
  제거한 키 ID는 같은 키를 되살릴 때만 다시 쓸 수 있습니다.

결과
  갱신 JAR  : /opt/app/java-crypto-kit-{version}.jar
  변경 항목 : crypto.keys.p1.type (pass -> (없음))
              ...
  제거 키   : p1

예제
  {update} config key remove --key-id p1 --operator ops
