config key remove - 키 목록에서 키 제거(새 JAR 생성)

사용법
  java -jar {jar} config key remove --key-id <ID>
       --operator <ID> [--reason <사유>] [--jar <jar>]
       [--out <jar> | --replace] [--yes]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --key-id <ID>     제거할 키 ID(필수)
  --operator <ID>   이력에 남길 수정자 ID(필수)
  --reason <사유>   이력에 남길 사유(필수, 없으면 대화형 터미널에서 질문)
  --jar <jar>       바꿀 JAR(선택, 기본: 실행 중인 JAR)
  --out <jar>       결과 JAR(선택, 기본 <이름>-cfg.jar)
  --replace         원본 교체(백업 후)
  --yes             CHANGE 확인 생략(사유는 생략할 수 없음)
  --admin-pass-file <파일>
                    관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                    없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko      이번 실행의 메시지 언어(선택)
  기본 키와 crypto.key.* AES 키는 제거할 수 없습니다. 제거한 키로 만든
  암호문은 결과 JAR로 복호화되지 않으므로 먼저 rekey로 옮깁니다.
  제거한 키 ID는 같은 키를 되살릴 때만 다시 쓸 수 있습니다.

결과
  생성 JAR  : /opt/app/java-crypto-kit-{version}-cfg.jar
  변경 항목 : crypto.keys.p1.type (pass -> (없음))
              ...
  제거 키   : p1

예제
  java -jar {jar} config key remove --key-id p1 --operator ops
