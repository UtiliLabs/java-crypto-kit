decrypt - 암호문 복호화(평문 표시, 대화형 터미널 전용)

사용법
  java [-D...] -jar {jar} decrypt
       [--config <파일>] [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --config <파일>   외부 Properties 파일(선택, encrypt와 같은 규칙)
  --admin-pass-file <파일>
                    관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                    없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko      이번 실행의 메시지 언어(선택)
  암호문은 인자로 받지 않고, 화면에 표시하지 않는 입력으로 받습니다.
  키는 암호문의 키 ID로 자동 선택합니다(pass·key 모두, 유형 지정 없음).

결과
  관리자 비밀번호(입력 숨김):   (먼저 관리자 인증, 그다음 암호문 입력)
  암호문(입력 숨김):
  복호화 결과: <평문>
  키 ID·인증 태그 검증에 실패하면 평문 없이 오류로 끝납니다
  (KEY_ID_MISMATCH: 등록되지 않은 키 ID, INTEGRITY 등).

예제
  java -jar {jar} decrypt
  java -jar {jar} decrypt --config app.properties
