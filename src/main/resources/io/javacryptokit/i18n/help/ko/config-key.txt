config key - JAR 내부 키 목록 관리(재빌드 없음)

명령(모든 키 변경은 새 JAR를 만들 때도 CHANGE 입력 또는 --yes)
  config key add      키 추가(기본 키는 --active일 때만 바뀜)
  config key use      유형별 기본 키 변경(다른 유형은 그대로)
  config key remove   키 제거(기본 키·crypto.key.* AES 키 제외)
  config key show     키 관리정보 조회, 원문 표시(--show)·내보내기(--export)
  명령별 옵션: config key add --help 처럼 명령 뒤에 --help
  모두 실행할 때마다 관리자 비밀번호를 확인합니다(--admin-pass-file 가능).

유형
  pass   Passphrase에서 AES 키 파생(PBKDF2, 키마다 새 Salt). 기본 유형
  key    32바이트 AES 키(keygen 형식)
  공식 JAR의 공개 기본 키: pass-default(pass), default(key, 기존 키)
  복호화는 암호문의 키 ID로 키를 고릅니다. 사용한 ID는 같은 키를 복원할 때만
  다시 쓸 수 있습니다. 키 교체는 새 ID로 추가 → use → rekey → remove 순입니다.

예제
  java -jar {jar} config key add --key-id p2 --operator ops
  java -jar {jar} config key use --key-id p2 --operator ops
