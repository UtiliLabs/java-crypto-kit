encrypt - 문자열(DB 비밀번호·사용자명 등) 암호화

사용법
  java [-D...] -jar {jar} encrypt
       [--type pass|key] [--key-id <ID>] [--config <파일>] [--lang en|ko]

옵션
  --type pass|key   키 유형(선택). 없으면 crypto.key.type(기본 pass)
  --key-id <ID>     등록된 키 ID(선택, 유형 자동). --type과 함께면 유형 확인
                    둘 다 없으면 그 유형의 기본 키(config show로 확인)
  --config <파일>   외부 Properties 파일(선택). 지정하지 않으면
                    -Dcrypto.config.file, 환경변수 CRYPTO_CONFIG_FILE,
                    JAR 내부 설정 순서로 찾습니다(Tomcat과 같음).
  --lang en|ko      이번 실행의 메시지 언어(선택)

결과
  암호화할 값(입력 숨김):
  ENC[v1:pass-default:...]
  한 줄 전체가 암호문입니다(같은 값도 매번 다른 결과). 키 ID가 들어 있어
  복호화할 때는 유형을 고르지 않습니다. base64 설정이면 B64[...]입니다.
  Tomcat Resource의 password="..."에 그대로 넣습니다(help tomcat).

예제
  java -jar {jar} encrypt
  java -jar {jar} encrypt --type key
  java -jar {jar} encrypt --key-id app-pass
