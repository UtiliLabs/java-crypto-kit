encrypt - DB 비밀번호·사용자명 등 값을 암호화

사용 형식
  java [-D...] -jar {jar} encrypt [--config <파일>] [--lang en|ko]

옵션
  --config <파일>   외부 Properties 파일(선택). 없으면 -Dcrypto.config.file → 환경변수 CRYPTO_CONFIG_FILE →
                    JAR 내장 설정 순서로 찾습니다(Tomcat과 같은 규칙).
  --lang en|ko      이번 실행의 메시지 언어(선택).

동작
  화면에 표시하지 않고 값을 입력받아 AES-256-GCM으로 암호화(매번 새 난수 IV)하고, 표준 출력에 암호문만 출력합니다:
  ENC[v1:<키ID>:<IV>:<암호문>] (crypto.output.encoding=base64이면 B64[...]). 같은 값도 매번 다른 암호문이 됩니다.

예제
  Windows PowerShell
    java -jar .\{jar} encrypt
    java -jar .\{jar} encrypt --config C:/secure/java-crypto-kit.properties
  Linux
    java -jar ./{jar} encrypt
    java -Dcrypto.key.source=file -Dcrypto.key.file=/etc/java-crypto-kit/app.key -jar ./{jar} encrypt

예상 결과
  암호화할 값 (DB 비밀번호 또는 사용자명, 화면에 표시되지 않음):
  ENC[v1:default:Qm9...:k3J...]
  한 줄 전체(ENC[부터 ]까지)를 Tomcat Resource의 password="..."에 넣습니다.

최소 Tomcat Resource 예(context.xml 또는 server.xml)
  <Resource name="jdbc/appDS" auth="Container" type="javax.sql.DataSource"
            factory="io.javacryptokit.jdbc.tomcat.EncryptedDataSourceFactory"
            driverClassName="org.mariadb.jdbc.Driver" url="jdbc:mariadb://db.example.internal:3306/app"
            username="app" password="ENC[v1:default:...]" maxTotal="20"/>
  Tomcat JDBC Pool은 crypto.pool.factory로 고릅니다(config help 참고).

대표 오류와 해결
  [사유: USAGE] 대화형 터미널이 필요합니다  -> Windows PowerShell·명령 프롬프트나 Linux 터미널(ssh)에서 직접 실행하세요
                                             (IDE 콘솔·파이프·리다이렉트·스크립트 불가, 값을 인자로 넘기는 방법은 없음).
  [사유: KEY_SOURCE] ...                     -> 키 파일·환경변수를 읽지 못함. doctor로 점검하세요.
  [사유: CONFIGURATION] ...                  -> 메시지에 나온 설정을 고치세요. config help 참고.

보안 주의
  - 값을 명령행 인자로 받지 않습니다(셸 기록·프로세스 목록 노출 방지).
  - 공개 기본 키로 만든 암호문은 누구나 복호화할 수 있습니다. 먼저 사용자 지정 키를 내장하세요(config embed-key).
  - WAS와 같은 설정(키·키ID)으로 암호화해야 합니다.

관련 명령: verify, decrypt, info, doctor, config embed-key
