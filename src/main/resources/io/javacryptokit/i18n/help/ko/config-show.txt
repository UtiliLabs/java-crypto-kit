config show - JAR 파일 안의 설정과 키 목록(관리자 인증, 외부 설정·-D 미반영)

사용법
  java -jar {jar} config show [--jar <jar>]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --jar <jar>    조회할 JAR(선택, 기본: 실행 중인 JAR)
  --admin-pass-file <파일>
                 관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                 없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko   이번 실행의 메시지 언어(선택)
  다른 JAR(--jar)을 보면 그 JAR의 관리자 비밀번호도 확인합니다.

결과(일부)
  JAR 파일  : java-crypto-kit-{version}.jar (버전 {version})
  상태      : 변경 2회 - 마지막 2026-11-22T05:30:12Z, 수정자 ops
  관리자    : 비밀번호 설정됨(민감 명령은 관리자 인증 필요)
  기본 유형 : pass
  기본 키   : pass=app-pass, key=key01
  키 목록   :
    key01: key, embedded, 사용자 지정, crypto.key.*
      키 지문: ab12cd34...(64자 전체)
    app-pass: pass, embedded, 사용자 지정
      키 지문: 3dca588c...(64자 전체)
      KDF: pbkdf2-sha256, 600,000회
      Salt: ...(Base64)   Salt SHA-256: ...(64자)
  설정 지문 : sha256:...      (설정 파일 내용의 식별값, 키 지문 아님)
  crypto.key.id = key01       (이어서 전체 내장 값, 키 값은 (비공개))
  외부 키는 등록된 지문을 표시합니다. 원문을 확인하려면 대화형 콘솔에서
  config key show --key-id <ID> --show 명령을 사용하세요.
  실제로 쓰는 키는 info·fingerprint. 이력이 손상됐으면 종료 코드 1.

예제
  java -jar {jar} config show
  java -jar {jar} config show --jar backup/old.jar
