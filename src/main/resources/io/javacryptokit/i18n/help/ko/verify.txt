verify - 암호문을 현재 키로 복호화할 수 있는지 확인(평문은 출력하지 않음)

사용 형식
  java [-D...] -jar {jar} verify [--config <파일>] [--value <암호문>] [--lang en|ko]

옵션
  --config <파일>       외부 Properties 파일(선택, encrypt와 같은 규칙).
  --value <암호문>      확인할 암호문(선택). 없으면 터미널에서 화면에 표시하지 않고 입력받습니다.
                        무인 배포 점검용이며 셸 기록에 남습니다.
  --lang en|ko          이번 실행의 메시지 언어(선택).

동작
  ENC[...] 또는 B64[...] 값을 현재 키·키ID로 복호화해 GCM 인증 태그를 확인하고 결과를 바로 지웁니다. 종료 코드 0이면
  같은 설정의 WAS도 복호화할 수 있다는 뜻입니다.

예제
  Windows PowerShell
    java -jar .\{jar} verify
    java -jar .\{jar} verify --value "ENC[v1:prod01:...]"
  Linux
    java -jar ./{jar} verify --config /etc/java-crypto-kit/app.properties
    java -jar ./{jar} verify --value 'ENC[v1:prod01:...]' && echo OK

예상 결과
  검증 성공: 현재 키로 복호화할 수 있습니다. (평문 미출력)

대표 오류와 해결
  [사유: KEY_ID_MISMATCH] -> 다른 키ID로 만든 암호문입니다. info로 crypto.key.id를 확인하세요.
  [사유: INTEGRITY]       -> 다른 키이거나 암호문이 손상됨. fingerprint로 키를 비교하세요.
  [사유: INVALID_TOKEN]   -> 한 줄 전체(ENC[ ... ])가 아닙니다. 공백 없이 다시 복사하세요.

보안 주의
  verify는 평문을 보여 주지 않습니다. 평문 확인은 decrypt(대화형, 확인 절차)로만 합니다.

관련 명령: encrypt, decrypt, fingerprint, rekey, doctor
