verify - 암호문을 등록된 키로 복호화할 수 있는지 검증(평문 미출력)

사용법
  java [-D...] -jar {jar} verify
       [--config <파일>] [--value <암호문>] [--lang en|ko]

옵션
  --config <파일>     외부 Properties 파일(선택, encrypt와 같은 규칙)
  --value <암호문>    검증할 암호문(선택). 없으면 화면에 표시하지 않고
                      입력받습니다. 자동화용이며 셸 기록에 남습니다.
  --lang en|ko        이번 실행의 메시지 언어(선택)
  키는 암호문의 키 ID로 자동 선택합니다.

결과
  OK
  실패하면 사유 코드와 함께 종료 코드 1
  (KEY_ID_MISMATCH: 등록되지 않은 키 ID, INTEGRITY: 다른 키 또는 손상).

예제
  java -jar {jar} verify
  java -jar {jar} verify --value 'ENC[v1:key01:...]'
