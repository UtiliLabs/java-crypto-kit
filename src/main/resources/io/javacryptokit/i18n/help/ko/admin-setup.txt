admin setup - CLI 관리자 비밀번호 최초 설정(같은 경로)

사용법
  {update} admin setup [--operator <ID>]
       [--pass-export <파일>]
       [--admin-pass-file <파일>] [--replace] [--lang en|ko]

옵션
  --replace         같은 경로에 저장하는 기존 호환 옵션.
  --operator <ID>   작업자 ID(이력 기록용, 생략하면 SYSTEM).
  --admin-pass-file <파일>
                    비대화형(CI 등): 새 비밀번호 한 줄이 든 파일
                    (권한 600 임시 파일, 쓰고 나서 삭제)
  --lang en|ko      이번 실행의 메시지 언어(선택)
  관리자 비밀번호가 없는 JAR에서만 실행합니다(설정된 JAR은 덮어쓰지 않음).
  대화형: 새 비밀번호 → 비밀번호 확인(2회, 화면 비표시).
  두 OS의 대화형 명령에서 최초 설정으로 진입할 수 있습니다.
  완료 후 같은 JAR로 원래 명령을 다시 실행합니다.

규칙
  10~128자, 영문자(A-Z, a-z)·숫자(0-9)·특수문자 각 1자 이상.
  특수문자는 ASCII 기호(!@#$% 등)이며 공백·한글 등은 쓸 수 없습니다.
  대문자·소문자를 따로 요구하지 않습니다. 운영은 12~16자 이상 권장.

결과
  랜덤 PASS (Passphrase)와 KEY (AES Key)를 같은 JAR에 생성합니다.
  갱신 후 SHA-256이 공식 배포본과 달라지는 것이 정상입니다.
  설정 JAR를 안전하게 백업하고 내장 키를 쓰는 모든 서버에 같은 JAR를 배치하세요.
  --pass-export <파일>은 최초 설정 때만 pass 복원 백업을 저장합니다.
  설정 후 내장 Passphrase 원문은 조회할 수 없습니다.

예제
  {update} admin setup
  {update} admin setup --admin-pass-file admin.pw
