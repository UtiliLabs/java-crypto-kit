file decrypt - file encrypt로 만든 파일(JCKF v1) 복호화

사용법
  java [-D...] -jar {jar} file decrypt --in <파일>
       --out <파일> [--config <파일>]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --in <파일>       암호화된 파일(필수)
  --out <파일>      결과 파일(필수).
                    이미 있으면 덮어쓰지 않습니다.
  --config <파일>   외부 Properties 파일(선택, encrypt와 같은 규칙)
  --admin-pass-file <파일>
                    관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                    없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko      이번 실행의 메시지 언어(선택)
  키는 파일 헤더의 키 ID로 자동 선택합니다. 모든 청크의 인증이 끝난 뒤에만
  결과 파일이 생깁니다(실패하면 결과 없음).

결과
  복호화 완료: data.jck -> data.csv (1048576바이트)

예제
  java -jar {jar} file decrypt --in a.jck --out a.pdf
  java -jar {jar} file decrypt --in data.jck --out data.csv
