help aws-kms - AWS KMS로 보호한 데이터 키 사용(crypto.key.source=aws-kms)

1) AWS SDK 선택 묶음 설치(aws-kms에만 필요)
   java-crypto-kit-aws-kms-lib-{version}.zip의 aws-kms-lib/*.jar를
   Tomcat은 CATALINA_BASE/lib에 두고, CLI는 -cp로 지정합니다
   (java -jar는 -cp를 무시). 클래스패스 CP(현재 폴더 기준):
   PowerShell: $CP = "{jar};aws-kms-lib/*"
   Linux     : CP="{jar}:aws-kms-lib/*"
2) 데이터 키 파일 만들기(한 번): kms datakey --help
3) 설정
   crypto.key.source=aws-kms          crypto.key.id=prod01
   crypto.aws.kms.key.id=alias/java-crypto-kit-prod
   crypto.aws.kms.data-key.file=/etc/java-crypto-kit/prod.datakey
   crypto.aws.region=ap-northeast-2   (비우면 SDK 기본 리전 체계)
4) 확인
   java -cp "$CP" io.javacryptokit.cli.CryptoCli doctor --offline
   java -cp "$CP" io.javacryptokit.cli.CryptoCli doctor

pass 키·추가 키는 config key add --source aws-kms --location <파일>
(pass는 파생한 AES 키를 같은 형식으로 KMS가 감쌈).
권한: WAS는 kms:Decrypt, 데이터 키 생성은 kms:GenerateDataKey 또는
kms:Encrypt. 자격증명은 AWS SDK 표준 체계(IAM 역할·프로필·환경변수)만 씁니다.
상세(CP 설정·오류별 원인·복구): docs/user-guide.md 8.2절
