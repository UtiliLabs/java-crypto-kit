help tomcat - Tomcat JNDI DataSource의 DB 비밀번호 복호화(DBCP2 기본)

1) JAR 배치: java-crypto-kit JAR(운영은 키를 내장한 JAR)와 JDBC 드라이버 JAR를
   CATALINA_BASE/lib에 복사합니다(java-crypto-kit JAR는 하나만).
2) 암호화: 같은 JAR로 encrypt를 실행해 ENC[v1:...]를 얻습니다.
3) Resource 수정: Tomcat이 읽는 Context 파일(예: 앱의 META-INF/context.xml)의
   <Resource>에 다음 두 속성을 지정합니다(username은 평문 또는 암호문).
     factory="io.javacryptokit.jdbc.tomcat.EncryptedDataSourceFactory"
     password="ENC[v1:...]"
   키는 암호문의 키 ID로 고르므로 pass·key 암호문 모두 쓸 수 있습니다.
   Tomcat JDBC Pool을 쓰려면 설정 하나로 JVM의 모든 Resource에 적용합니다:
     crypto.pool.factory=org.apache.tomcat.jdbc.pool.DataSourceFactory
4) 외부 설정 파일을 쓸 때만 -Dcrypto.config.file=<파일>을 추가합니다.
   Linux bin/setenv.sh, Windows 콘솔 bin/setenv.bat의 CATALINA_OPTS,
   Windows 서비스는 서비스 설정의 Java Options.
5) Tomcat 재시작 후 애플리케이션에서 JNDI 조회, getConnection(), SQL로 확인

지원: Tomcat 11.0(Java 17+), 10.1(Java 11+), 9.0(Java 8+), 8.5(Java 8+, 레거시)
구형 Oracle JDK 8(8u161 미만)은 무제한 암호 정책이 필요합니다
(java.security의 crypto.policy=unlimited).
오류: Tomcat 로그의 [java-crypto-kit] [사유: 코드] 줄(조치: 가이드 9.3절)
