admin password change - CLI 관리자 비밀번호 변경(현재 JAR, 대화형 전용)

사용법
  {update} admin password change [--operator <ID>]
       [--reason <사유>] [--replace] [--lang en|ko]

옵션
  --operator <ID>   작업자 ID(이력 기록용). 없으면 묻습니다.
  --reason <사유>   변경 사유(필수, 없으면 묻습니다)
  --lang en|ko      이번 실행의 메시지 언어(선택)
  입력 순서: 현재 비밀번호 → 작업자 ID·사유(옵션이 없을 때) → 새 비밀번호
  → 비밀번호 확인. 새 비밀번호는 admin setup과 같은 규칙이고 현재 비밀번호와
  같으면 거부합니다. 현재 비밀번호를 모르면 바꿀 수 없습니다(인증 없는
  초기화 기능 없음, 분실 시 사용자 가이드 12.8).

결과
  같은 JAR에 새 검증값과 변경 이력을 저장합니다. 기존 키와 암호문은 유지합니다.
  변경 전에 직접 복사한 JAR는 이전 비밀번호로 열립니다.

예제
  {update} admin password change --operator ops
