admin password change - CLI 관리자 비밀번호 변경(새 JAR, 대화형 전용)

사용법
  java -jar {jar} admin password change [--operator <ID>]
       [--reason <사유>] [--out <jar>] [--lang en|ko]

옵션
  --operator <ID>   작업자 ID(이력 기록용). 없으면 묻습니다.
  --reason <사유>   변경 사유(필수, 없으면 묻습니다)
  --out <jar>       결과 JAR(선택, 기본 다음 -configured-N.jar)
  --lang en|ko      이번 실행의 메시지 언어(선택)
  입력 순서: 현재 비밀번호 → 작업자 ID·사유(옵션이 없을 때) → 새 비밀번호
  → 비밀번호 확인. 새 비밀번호는 admin setup과 같은 규칙이고 현재 비밀번호와
  같으면 거부합니다. 현재 비밀번호를 모르면 바꿀 수 없습니다(인증 없는
  초기화 기능 없음, 분실 시 사용자 가이드 12.8).

결과
  관리자    : 비밀번호 변경 완료
  생성 JAR  : C:\work\java-crypto-kit-{version}-configured-2.jar
  원본 JAR  : ...-configured.jar (그대로, 이전 비밀번호 유지)
  작업자    : ops
  사유      : 정기 변경
  안내      : 생성 JAR을 쓰고, 필요 없는 원본 JAR은 직접 폐기하세요.
  키·암호문·이력은 그대로입니다. 원본 JAR은 이전 비밀번호로 계속 열리므로
  보관·폐기를 직접 정합니다.

예제
  java -jar {jar} admin password change --operator ops
