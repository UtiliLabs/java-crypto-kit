rekey - 기존 암호문을 다른 키(새 키 ID)로 다시 암호화(평문 미출력)

사용법
  java [-D...] -jar {jar} rekey
       [--type pass|key] [--key-id <ID>]
       [--from-config <파일> | --from-jar <jar>]
       [--to-config <파일> | --to-jar <jar>]
       [--value <암호문>] [--admin-pass-file <파일>] [--lang en|ko]

옵션(하나 이상 지정, 지정하지 않은 쪽은 현재 실행 설정)
  --type pass|key        대상 키 유형(선택, 없으면 기존 암호문과 같은 유형)
  --key-id <ID>          대상 키 ID(선택, 유형 자동). --type·--key-id만 주면
                         같은 설정 안의 다른 키로 바꿉니다(유형 간도 가능).
  --from-config <파일>   이전 설정 = 실행 중인 JAR 값 + 이 Properties
  --from-jar <jar>       이전 설정 = 그 JAR의 내장 값(예: 키를 바꾸기 전 JAR)
  --to-config <파일>     신규 설정 = 실행 중인 JAR 값 + 이 Properties
  --to-jar <jar>         신규 설정 = 그 JAR의 내장 값
  --value <암호문>       다시 암호화할 암호문(선택, 없으면 입력 숨김으로 받음)
  --admin-pass-file <파일>
                         관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                         없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko           이번 실행의 메시지 언어(선택)

결과
  ENC[v1:key02:...]      (표준 출력에 새 암호문 한 줄만)
  이전 키는 기존 암호문의 키 ID로 고르고, 새 암호문이 대상 키로 복호화되는
  것을 확인한 뒤 출력합니다. 같은 키 ID·같은 키로는 바꾸지 않습니다.
  공개된 기본 키를 선택하면 실패합니다.

예제(backup/old.jar, new.jar에 각 키가 설정되어 있음)
  java -jar {jar} rekey --from-jar backup/old.jar
  java -jar {jar} rekey --to-jar new.jar
  java -jar {jar} rekey --key-id app-pass
