config history - JAR 내장 설정의 성공한 변경 전체를 최초 변경부터 조회

사용 형식
  java -jar {jar} config history [--jar <jar>] [--lang en|ko]

옵션
  --jar <jar>    조회할 JAR(선택). 기본값: 실행 중인 JAR.
  --lang en|ko   이번 실행의 메시지 언어(선택).

기록 내용(성공한 config set / config embed-key만. 실패·변경 없음은 기록하지 않음)
  변경 순번, UTC 수정 시각, 수정자(--operator), 명령, 사유(--reason), 바꾼 설정마다 이름·이전 값·변경 후 값.
  비밀값은 절대 기록하지 않습니다. 내장 키 변경은 "crypto.key.embedded: (비공개) -> (교체됨)"과 키ID 변경으로만 남습니다.
  새 JAR를 만들거나 --replace를 해도 전체 이력이 그대로 옮겨집니다. 최초 빌드 일시는 Manifest에서 읽습니다.

무결성 검사
  순번, SHA-256 해시 체인, 변경마다의 설정 지문, 빌드 때의 설정 지문을 확인합니다. 하나라도 맞지 않으면(파일 손상,
  config set 밖에서 설정 수정) 정상 이력으로 보여 주지 않고 [사유: INTEGRITY]로 종료 코드 1을 돌려주며,
  config set·embed-key도 그 JAR를 변경하지 않습니다.
  이 검사는 실수·단순 수정 탐지용입니다. 위변조 방지 감사 로그가 아닙니다(JAR를 수정할 수 있는 사람은 이력도 다시
  쓸 수 있음). 수정자 ID는 기록일 뿐 본인 인증이 아닙니다.

예제
  Windows PowerShell
    java -jar .\java-crypto-kit-{version}-configured.jar config history
  Linux
    java -jar ./{jar} config history --jar /opt/tomcat/lib/{jar}

예상 결과
  #1  2026-11-21T05:30:12Z (UTC)  수정자 example-admin  명령 config set
      crypto.lang: ko -> en
  #2  2026-11-21T05:40:00Z (UTC)  수정자 example-admin  명령 config embed-key
      사유: user-provided key
      crypto.key.embedded: (비공개) -> (교체됨)
      crypto.key.id: default -> prod01
  한 번도 바꾸지 않은 JAR는 "변경 이력 없음(최초 빌드 상태)"으로 표시합니다.

관련 명령: config show, config set, config embed-key
