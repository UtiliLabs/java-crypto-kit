config history - JAR 내부 설정의 변경 이력(관리자 인증, 최초 변경부터)

사용법
  java -jar {jar} config history
       [--type pass|key | --all] [--jar <jar>]
       [--admin-pass-file <파일>] [--lang en|ko]

옵션
  --type pass|key   그 유형의 키에 관한 변경만(생략하면 pass)
  --all             저장된 전체 이력(두 유형, 일반 설정, 관리자 비밀번호 기록)
  --jar <jar>       조회할 JAR(선택, 기본: 실행 중인 JAR)
  --admin-pass-file <파일>
                    관리자 비밀번호 파일(비대화형 인증, 한 줄, 권한 600)
                    없으면 관리자 비밀번호를 숨김 입력으로 묻습니다
  --lang en|ko      이번 실행의 메시지 언어(선택)
  --type과 --all은 함께 쓸 수 없습니다. 거르기 전에 전체 이력을 검증하며
  원래 순번을 그대로 보여 줍니다.

결과(일부, --type key)
  이력 검증 : 정상(3건, 해시 체인·현재 설정 일치)
  표시 범위 : key 관련 1건(전체 3건)

  #2  2026-11-22T05:30:12Z  수정자 ops  config embed-key  [key]
      사유: 운영 키 교체
      crypto.key.id: key-<생성 ID> -> key01
      키 key01: (없음) -> key, embedded, crypto.key.*, 파일
        키 지문: ab12cd34...(64자 전체)
  성공한 변경만 기록하고 관리정보(전체 지문·KDF·반복 횟수·Salt·작업자·사유)는
  마스킹 없이 보여 줍니다. 키 원문·관리자 비밀번호는 이력에 없습니다. 이전
  형식이라 값이 없는 항목은 (기록 없음)으로 구분합니다. 관리자 비밀번호
  설정·변경은 --all에서만 [관리자]로 보입니다. 이력이 손상됐거나 현재 설정과
  맞지 않으면 [사유: INTEGRITY], 종료 코드 1.

예제
  java -jar {jar} config history
  java -jar {jar} config history --type key --jar new.jar
  java -jar {jar} config history --all
