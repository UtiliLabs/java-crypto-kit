java-crypto-kit CLI {version} - 범용 Java 보안 도구

사용법: java [-D...] -jar {jar} <명령> [옵션]

관리자(CLI를 처음 쓸 때 1회 설정)
  admin setup              관리자 비밀번호 최초 설정(새 JAR)
  admin password change    관리자 비밀번호 변경(새 JAR)
문자열
  encrypt                  문자열 암호화
  decrypt *                문자열 복호화
  verify                   암호문 검증(평문 미출력)
파일
  file encrypt             파일 암호화
  file decrypt *           파일 복호화
키
  keygen *                 AES 키 파일 생성
  fingerprint              키 지문 확인
  rekey *                  다른 키로 재암호화
  kms datakey *            AWS KMS 데이터 키 파일 생성
설정·진단
  config show *            JAR 내부 설정·키 목록
  config history *         설정 변경 이력
  config set *             JAR 설정 변경(새 JAR)
  config embed-key *       AES 키를 JAR에 내장(새 JAR)
  config key add *         키 추가(새 JAR)
  config key use *         기본 키 변경(새 JAR)
  config key remove *      키 제거(새 JAR)
  config key show *        키 관리정보·원문 확인(--show, --export)
  info                     실제 적용 설정
  doctor                   설정·기능 점검

독립 보안 API
  api --help               독립 Java 보안 API 명령과 예제

* 실행할 때마다 관리자 비밀번호 확인(비대화형: --admin-pass-file <파일>).
  Java API·Tomcat 자동 복호화에는 관리자 비밀번호가 필요 없습니다.
키 유형: pass(Passphrase, 기본), key(AES 키). 암호화는 --type·--key-id로
고르고, 복호화는 암호문의 키 ID로 키를 자동 선택합니다.
상세: help <명령>   (예: help config set, decrypt --help)
예제 조회: <명령> --examples (예: file --examples)
설정: help config    키 목록: help config key
연동: help tomcat / help vault / help aws-kms
모든 명령: --lang en|ko(이번 실행 언어), --help(명령 도움말)
외부 설정 파일: --config <파일>, -Dcrypto.config.file, CRYPTO_CONFIG_FILE
-D<설정>=<값>은 java와 -jar 사이에 둡니다. 예:
  java -Dcrypto.lang=en -jar {jar} info
